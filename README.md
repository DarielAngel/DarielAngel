## 👨‍💻 About me

I'm a **Computer Science Engineer** (Universidad de las Ciencias Informáticas, 2025) working as a **software developer at XEJEL**. I build complete systems end to end: I design the database, write the API, build the interface and get it running on a server — with automated tests, CI and monitoring.

- 🛒 My largest project is a **microservices e-commerce platform**: 11 .NET 8 services, Vue 3 storefront + admin panel, RabbitMQ events, PayPal, and **750+ automated tests** on GitHub Actions.
- ⚖️ I built a **scheduling system for a province's lawyers** in Express + Vue 3, then migrated it entirely to **Django** keeping the same database.
- 🧠 I enjoy algorithms and AI: former **ICPC** competitor, contributor to the Spanish translation of **cp-algorithms**, and author of an in-browser **BDI multi-agent city simulation**.
- 🤖 I use AI assistants (Claude, Copilot) to move faster — **I own the architecture, review every change and cover it with tests.**
- 🌎 Based in Cuba (UTC−5/−4, same as US East Coast) · 🗣️ Spanish (native), English (B1, technical & written).
